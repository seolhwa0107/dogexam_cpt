# dogexam_cpt

반려견스타일리스트 3급 필기 문제 풀이 사이트입니다. 정적 HTML/CSS/JavaScript로 만들었으며 GitHub Pages에 배포합니다.

## 사이트 구성

- `site/`: GitHub Pages에 배포되는 사이트
- `site/data/chapter-N.json`: 챕터별 문제와 선택지 데이터 (1~6장, 총 598문항)
- `site/data/answers/chapter-N.json`: 1~6장 정답 데이터
- `.github/workflows/deploy-pages.yml`: `main` 변경 시 GitHub Pages 자동 배포

각 챕터의 문제 풀이 화면은 답안을 브라우저에 저장합니다. 단일 선택은 답을 누르면 바로 채점하고, 복수 선택은 선택을 확인하면 채점합니다. 원본에서 문항이나 선택지가 확인되지 않은 문제는 목록에 표시하되 풀이 선택을 비활성화합니다. 현재 선택지까지 확인되어 풀이할 수 있는 문항은 1장 94개, 2장 98개, 3장 99개, 4장 98개, 5장 95개, 6장 81개입니다.

모의시험 화면에서 챕터별 무작위 10문항 채점 시험과 6개 챕터에서 각각 10문항씩 출제되는 전체 60문항 모의시험을 이용할 수 있습니다. 전체 시험은 총점 60점 이상이면서 모든 챕터 정답률이 40% 이상이어야 합격입니다. 복수 정답은 선택한 답의 구성까지 맞아야 정답으로 처리합니다. 선택지가 불완전하거나 원본 정답이 선택지 라벨이 아닌 문항은 자동 채점과 시험 출제에서 제외합니다.

## 정답 데이터 추가

각 챕터의 정답 파일은 `site/data/answers/chapter-N.json`에 둡니다. 문항 ID를 키로 쓰고 단일 정답은 선택지 라벨, 복수 정답은 라벨 배열로 입력합니다.

```json
{
  "chapterNumber": 1,
  "answers": {
    "c1-q1": "①",
    "c1-q6": ["④", "⑤"]
  }
}
```

문항 데이터의 `id`와 정확히 일치해야 합니다. 원문에 선택지 라벨 대신 순서 문자열로 인쇄된 정답과 답안 공란도 원본 값을 보존하지만 자동 채점에는 포함하지 않습니다. 챕터 데이터는 `site/data/chapter-N.json`에 있습니다.

## GitHub Pages 설정

저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정합니다. 이후 `main` 브랜치에 커밋이 올라오면 워크플로가 사이트를 배포합니다.

예상 주소: <https://seolhwa0107.github.io/dogexam_cpt/>

GitHub Pages로 제공되는 사이트와 데이터 파일은 공개 인터넷에서 볼 수 있습니다. 저장소가 비공개여도 페이지 방문자는 사이트 자료를 내려받을 수 있습니다. 비공개 저장소 Pages 이용 자격은 GitHub 플랜에 따라 달라질 수 있습니다.
